## Provider Setup
It is essential to add the `LocationFinderProvider` at the root of your application. This will provide the `useLocationFinder` hook to all of your components. This library uses HeroUI 3 for some components: install `@heroui/react` and load its styles in your Tailwind 4 stylesheet with `@import "@heroui/styles";`, plus an `@source` line for this package.
<Source code={`
// 1. import the LocationFinderProvider component.
import { LocationFinderProvider } from '@ef2/react-gm-location-finder';

// 2. Set Google Maps API key and libraries.
const { isLoaded } = useJsApiLoader({
    id: 'google-map-script',
    googleMapsApiKey: 'YOUR_API_KEY',
    libraries: ['places', 'geometry'],
    language: 'nl',
    region: 'nl'
});

// 3. Wrap your application in the LocationFinderProvider.
<LocationFinderProvider loading={!isLoaded} locations={locations}>
    {children}
</LocationFinderProvider>
`}/>
